# mirror —— 源码镜像区（可运行的开源化版本）

这里的代码来自我在职期间主导研发的两个内部系统（一个多 Agent 后端平台、一个配套的前端控制台）。

搬到这里的不是项目副本，而是一次**人工改造**的结果：删除全部业务耦合部分，把内部依赖替换成公开可得的实现，使它能在一台干净机器上跑起来。目的是让"我做过什么"这件事既能被读到代码，也能被跑起来验证。

## 性质声明

- **可本地跑通**：按下方步骤安装依赖并启动，后端与前端可用，核心链路可走通
- **不保证生产可用**：没有部署方案、没有并发与运维设计、没有安全加固
- **不依赖任何内部资源**：不连组织内网、不需要内部账号、不使用真实凭证
- **经脱敏**：内部事实（内网地址与端口、凭证位、内部系统与产品名、业务专有名词、业务数据模型、个人标识）已删除、泛化或替换
- **不接受 PR**：这是作品展示，不是维护中的开源项目

## 处置规则（四级判定）

| 判定 | 动作 | 验收 |
|---|---|---|
| 保留 | 零改动 | 与源文件逐字节一致，仅追加来源声明头 |
| 删除 | 整块移除 | 该文件不出现在此目录 |
| 保留机制 / 删除内容 | 行级删除 | 删除行可逐条列举 |
| 替换 | 内部依赖换成公开实现或本地 mock | 替换点可逐条列举，替换物同样过脱敏闸门 |

两条硬约束：

- **减法优先**：能用删除解决的一律删除，替换只用在"不替换就跑不起来"的位置
- **不伪造能力**：本地 mock 不会被包装成真实能力，未覆盖的功能在 README 中注明
