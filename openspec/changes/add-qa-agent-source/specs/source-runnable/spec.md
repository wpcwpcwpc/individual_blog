## ADDED Requirements

### Requirement: 可运行性目标与验收范围

镜像区 SHALL 以"本地可启动、核心链路可走通"为验收标准。验收项 SHALL 在改造动工前显式列出并记录；验收范围一旦确定，扩张 SHALL 走变更文档修订，MUST NOT 在实施中默认增加。

#### Scenario: 后端可启动

- **WHEN** 在一台干净机器上按镜像区 README 的步骤操作
- **THEN** 依赖可安装、服务可启动、健康检查返回正常

#### Scenario: 前端可启动

- **WHEN** 按 README 步骤安装并启动前端
- **THEN** 界面可访问，且能与本地后端建立连接

#### Scenario: 对话链路可走通

- **WHEN** 创建一个会话并发送一条消息
- **THEN** 能收到流式输出，且流式输出来自公开供应商的 OpenAI 兼容 API

#### Scenario: 验收范围扩张

- **WHEN** 实施过程中希望把已删除的功能"顺便恢复"
- **THEN** 必须先修订本变更的验收范围，MUST NOT 直接实施

### Requirement: 内部依赖的替换契约

当某内部依赖不替换则无法启动时，SHALL 采用 `REPLACE` 处置：以公开可得实现或本地 mock 替换。替换 SHALL 满足：不硬编码内部事实、配置经环境变量注入、附值全为占位的示例配置。`REPLACE` SHALL 仅用于启动必需的位置，能用删除解决的一律删除。

#### Scenario: 替换内部网关

- **WHEN** 模型层依赖组织内部网关
- **THEN** 替换为公开供应商的 OpenAI 兼容客户端；MUST NOT 保留内部网关名称、地址或其专属协议分支

#### Scenario: 替换内部存储

- **WHEN** 持久化层依赖组织内部数据库服务
- **THEN** 替换为本地可跑的最小实现（同类型实例或本地文件存储），且连接串取自环境变量

#### Scenario: 可用删除解决时

- **WHEN** 某内部依赖只服务于已删除功能
- **THEN** MUST 直接删除依赖，MUST NOT 为实现"完整感"而替换

### Requirement: 运行期不得暴露内部事实

本地运行 SHALL NOT 依赖任何内部资源，也 SHALL NOT 在输出中暴露内部事实。启动日志、错误信息、界面文案与默认配置值 MUST NOT 含内网地址、内部主机名、内部系统名、业务专有名词或个人标识。

#### Scenario: 启动输出检查

- **WHEN** 完成本地启动
- **THEN** 启动日志中无内网地址与内部系统名

#### Scenario: 报错路径检查

- **WHEN** 模拟一次依赖不可用（如关闭本地数据库）
- **THEN** 错误信息只描述通用原因，MUST NOT 输出内部主机名、内部服务名或真实路径

#### Scenario: 界面文案检查

- **WHEN** 打开前端界面
- **THEN** 页面文案不含业务专有名词与内部系统名

### Requirement: 可运行性不得成为脱敏豁免理由

为可运行而新增的代码与配置 SHALL 与搬运内容受同一套脱敏约束：`REPLACE` 产物 SHALL 被纳入扫描，MUST NOT 因"由作者新写"而加入豁免清单。

#### Scenario: 新增适配层

- **WHEN** 为一个内部依赖编写替换实现
- **THEN** 该文件 SHALL 位于镜像区内并纳入构建前扫描范围，命中禁出词即构建失败

#### Scenario: 新增示例配置

- **WHEN** 提供示例配置文件
- **THEN** 其中所有值 MUST 为占位，MUST NOT 出现真实地址、凭证或组织标识
